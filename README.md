# 四维人格测评网站

当前为免费静态试测版。完成 48 道简体中文题后，浏览器立即生成四维测评报告。答题进度、历史记录和报告保存在同一域名下的当前浏览器。题库尚未完成正式验证。

## Netlify 部署

将 `public` 文件夹拖入 Netlify Drop。也可导入代码库，Base directory 和构建命令留空，发布目录由仓库根目录的 `netlify.toml` 设为 `public`。部署不需要安装依赖或配置环境变量。

## 本地验证

在本目录运行 `npm run dev`，打开终端打印的地址。运行 `npm test` 可检查计分逻辑和保留的支付服务逻辑。

微信支付服务源码位于 `netlify/payment` 和 `netlify/lib`，凭证字段仍见 `.env.example`。恢复收费时需重新接入付款界面并独立验收。
